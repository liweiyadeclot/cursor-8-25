## ⚙️ 配置变化

### Dify HTTP 请求节点

**请求体**可以添加更多参数：

```json
{
  "prompt": "{{#workflow.mcp_prompt#}}",
  "headless": false,
  "browser": "chrome",
  "timeout": 300
}
```

**参数说明**：
- `headless`: `false` = 显示浏览器（推荐，便于调试）
- `browser`: `"chrome"` / `"firefox"` / `"webkit"`
- `timeout`: 总超时时间（秒）

## 🔧 如果遇到问题

### 问题 1：Playwright 未安装

**错误**：`ModuleNotFoundError: No module named 'playwright'`

**解决**：
```bash
pip install playwright
playwright install chromium
```

### 问题 2：浏览器启动失败

**错误**：`Browser launch failed`

**解决**：
1. 确保已安装浏览器：`playwright install chromium`
2. 检查系统权限
3. 尝试使用无头模式：`"headless": true`

### 问题 3：选择器找不到元素

**现象**：某些步骤失败

**解决**：
1. 查看日志中的错误信息
2. 检查页面是否已加载完成
3. 可能需要调整选择器策略
