# Qwen 2.5 7B 报销信息提取测试

这个模块用于测试使用Qwen 2.5 7B模型从自然语言中提取报销信息的功能。

## 前置条件

1. 安装并运行Ollama
2. 下载Qwen 2.5 7B模型
3. 安装Python依赖

## 安装步骤

### 1. 安装Ollama和模型

```bash
# 安装Ollama (如果尚未安装)
# 下载地址: https://ollama.ai/

# 拉取Qwen 2.5 7B模型
ollama pull qwen2.5:7b

# 启动Ollama服务
ollama serve
```

### 2. 安装Python依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 运行测试脚本

```bash
python test_qwen_extraction.py
```

### 测试用例

脚本包含以下测试用例：

1. **差旅费报销**：
   - 输入：张三，学工号2021001，技术部，差旅费500元，北京到上海出差，2024年1月15日，预约明天下午2点报销

2. **办公用品报销**：
   - 输入：李四，财务部，办公用品200元，购买打印纸和笔，项目号P2024001

3. **劳务费报销**：
   - 输入：王五，劳务费1000元，讲课费，发放事由：给学生上课

4. **培训费报销**：
   - 输入：赵六，培训费800元，参加技术培训，预约下周一上午10点，地点：财务处

### 交互式测试

运行脚本后，可以选择进入交互式测试模式，手动输入报销信息进行测试。

## 输出格式

模型会按照以下7个阶段提取信息：

1. **登录阶段**：用户名、密码
2. **项目信息**：项目号、附件张数、支付方式
3. **报销科目**：科目类型、金额
4. **报销人员**：学工号、银行卡信息
5. **预约报销**：报销时间、地点
6. **差旅信息**：姓名、人员类型、出差地点
7. **劳务信息**：劳务费类型、发放事由

## 故障排除

### 模型未找到
如果提示模型未安装，请确保：
1. Ollama服务正在运行
2. 已成功下载qwen2.5:7b模型
3. 可以通过 `ollama list` 命令看到模型

### 连接失败
如果连接Ollama服务失败，请检查：
1. Ollama服务是否在11434端口运行
2. 防火墙设置是否阻止了连接
3. 网络连接是否正常

### 解析错误
如果JSON解析失败，可能是：
1. 模型输出格式不符合预期
2. 提示词需要优化
3. 模型版本问题
