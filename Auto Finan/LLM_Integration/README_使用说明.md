# Excel批量处理器使用说明

## 📋 功能说明

`excel_batch_processor.py` 是一个批量处理工具，可以直接从Excel文件读取财务数据，生成对应的Playwright MCP自动化提示词。

## 🚀 快速开始

### 1. 修改Excel文件路径（如需要）

打开 `excel_batch_processor.py`，修改第128行的文件路径：

```python
# ===== 配置区域：可修改Excel文件路径 =====
EXCEL_FILE_PATH = r"C:\Users\FH\source\repos\Auto Finan\Auto Finan\420财务050823.xlsx"
```

### 2. 运行程序

```bash
cd "C:\Users\FH\source\repos\Auto Finan\Auto Finan\LLM_Integration"
python excel_batch_processor.py
```

### 3. 输入工作表名

程序会提示你输入工作表名称：

```
请输入工作表名称（如：3-报销、3-差旅、3-劳务）：
```

输入示例：
- `3-报销` - 处理报销业务数据
- `3-差旅` - 处理差旅业务数据
- `3-劳务` - 处理劳务业务数据

### 4. 查看输出结果

程序会自动处理该工作表中的所有序号，并显示：
- ✅ 每个序号提取的JSON数据
- ✅ 每个序号生成的MCP提示词
- ✅ 处理统计信息

## 🔧 支持的业务类型

### 1. 报销业务（3-报销）
- 登录信息
- 项目信息
- 科目信息（支持多个）
- 转卡人员信息（支持多个）
- 预约信息

### 2. 差旅业务（3-差旅）
- 登录信息
- 项目信息
- 出差人员信息（支持多个）
- 差旅费用信息（支持多个）
- 转卡人员信息（支持多个）
- 预约信息

### 3. 劳务业务（3-劳务）
- 登录信息
- 项目信息
- 劳务信息（单个）
- 劳务人员信息（支持多个）
- 预约信息

## 📝 Excel表格要求

### 必需列：
- **序号**：用于分组数据（同一序号的多行会自动合并）
- **账号** / **登录界面工号**：登录用户名
- **密码** / **登录界面密码**：登录密码
- **业务大类** / **选择业务大类**：业务类型标识

### 可选列（根据业务类型）：
- 报销项目号、附件张数、支付方式、备注、特殊事项说明
- 科目、金额（报销业务）
- 转卡信息工号、卡号尾号、个人金额
- 出差人、姓名、人员类型（差旅业务）
- 省份、起、迄、飞机票、火车票、其他交通费、住宿费
- 人员类别、酬金性质、劳务费类型、发放事由（劳务业务）
- 工号/证件号、单笔录入金额
- 日期、校区

## ⚙️ 字段类型映射

程序使用 `field_type_mapping.xlsx` 文件来识别字段类型：

| 标记 | 说明 | 生成格式 |
|------|------|----------|
| `i` | 输入框 | 在{label}输入框中输入{value} |
| `c` | 下拉框 | 在{label}下拉框中选择{value} |
| `r` | 单选按钮 | 点击{label}radio button |
| `d` | 日期选择 | 选择日期{label}为{value} |
| `empty` | 自定义格式 | {label}内容为{value} |
| 空 | 参考信息 | 跳过不生成 |

## 🎯 核心优势

- ✅ **零LLM调用**：直接从Excel转JSON，速度极快
- ✅ **批量处理**：自动处理所有序号，无需手动逐个操作
- ✅ **100%确定性**：基于规则转换，不受上下文长度限制
- ✅ **多行自动合并**：同一序号的多行数据自动归并为数组

## 🐛 故障排查

### 问题1：未找到数据
- 检查工作表名是否正确
- 检查Excel第一列是否有"序号"表头
- 检查数据行是否从第2行开始

### 问题2：字段未生成操作
- 检查 `field_type_mapping.xlsx` 中是否有该字段的映射
- 检查字段的"标记"列是否为空（空标记会跳过）

### 问题3：业务类型识别错误
- 检查Excel中"业务大类"或"选择业务大类"列的值
- 支持的值：报销业务、业务出差旅费、酬金业务
